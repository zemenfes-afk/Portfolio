# Portfolio

This portfolio is a Vite + React app designed for static deployment.

## Local development

```bash
npm install
npm run dev -- --host 0.0.0.0
```

## Production build

```bash
npm run build
```

## Hugging Face deployment

This project is prepared for Hugging Face Spaces with Docker.

1. Push this repository to GitHub.
2. Create a new Space on Hugging Face and choose "Docker" as the SDK.
3. Select the repository and branch.
4. The app will build using the included Dockerfile.
5. The public URL will be generated by Hugging Face automatically.

Important:
- The Dockerfile listens on port 7860, which is the required port for Hugging Face Spaces.
- The app is served via Nginx from the built static files in the dist folder.
